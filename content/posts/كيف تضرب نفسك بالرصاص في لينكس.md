How to shoot yourself on a foot (linux)
`sudo chmod -R 777 /usr/bin`
you now changed permissions for sudo command so you can't now use sudo cause it must be owned by uid 0 
I waste about an hours to solve that shit

Solution 

1- boot from live USB any unix sys or recover mode if you are using ubuntu 
2- mount your root directory into (`/mnt`) to get disk (`sudo fdisk -l`)
3- run command `sudo chwon root:root /mnt/usr/bin/sudo`
4- run command `sudo chmod 4755 /mnt/usr/bin/sudo`
